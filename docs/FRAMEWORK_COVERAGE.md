# Framework Coverage — SDG GRC Proof Portfolio

Owner: Badr Karim  
As-of: 2026-02-28

This portfolio is anchored on a real system (SDG) and documents governance, risk, compliance, and assurance artifacts with evidence links.

## Frameworks included
### Governance
- COBIT 2019 (governance objectives-to-metrics + scorecard)

### Security program / controls
- NIST CSF 2.0 (current/target profile + gap plan)
- ISO 27001/27002 (ISMS scope + topic-based SoA + control/evidence mapping)

### Risk management
- ISO 31000 (risk methodology + scoring + acceptance)
- ISO 27005 (security risk register + treatment plan)

### Assurance / audit readiness
- SOC 2 (readiness matrix + evidence request list + executed workpapers + evidence tracker)

### Compliance program
- ISO 37301 (CMS charter + obligations register; applicability is conditional by sector/state)

## Evidence and defensibility rules
- Evidence is stored under: artifacts/14_Evidence/YYYY-MM/
- Naming: docs/EVIDENCE_NAMING_STANDARD.md
- Evidence is sanitized (no secrets, no OTP codes, no sensitive query results).
